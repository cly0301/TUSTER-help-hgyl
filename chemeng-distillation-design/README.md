# 化工原理课程设计助手 · 使用说明（小白版）

这是一份**「乙醇-水筛板精馏塔」课程设计**的自动助手。你只要告诉它你的学号，它就会帮你：

- 把学号换成设计参数（进料/塔顶/塔釜浓度、回流比）
- **一组一组问你「要自己选的设计参数」**——每组给出可行范围和最佳建议值；**你每定一组，它立刻算一遍**，告诉你这个选择让塔径/塔高/压降/校核结果变成什么样，以及后面几组参数现在该取什么范围
- 自动算出全部结果（物料衡算 → 回流比 → 理论/实际塔板数 → 塔径 → 塔板结构 → 流体力学校核 → 负荷性能图 → 塔高 → 冷凝器 → 五种接管管径），并自动校核
- 按模板生成《设计说明书》——**论述文字沿用模板，数值全部换成你的**
- 生成一份「装配图绘制指导」（告诉你画装配图要用的所有数据）

---

## 一、你需要准备什么

1. 一台能联网的电脑（Windows）
2. 装好 **Python**（用来跑计算脚本，可选）
3. 已经装好 **DeepSeek Harness（DSH）**（用来加载这个 skill）

> 如果你只会在 DSH 里聊天，Python 可以不装——计算脚本只是备用的复核工具。

---

## 二、怎么装（下载后放哪里）

**必须下载整个文件夹，不能只拿 SKILL.md 一个文件。** SKILL.md 只是「指令书」，它干活要靠同一目录下的一批配套文件：

| 文件 | 少了会怎样 |
|---|---|
| `resources/design_calc.py` | **算不出任何数**——全部结果都出自这个脚本 |
| `resources/ethanol-water-vle.csv` | 脚本读不到气液平衡数据，直接跑不起来 |
| `resources/模板原文_14429.txt` | 说明书失去底稿，论述文字对不上课程要求 |
| `14429 设计说明书107.pdf` | 查图用的关联图（史密斯图等）看不到 |
| `resources/课件要点_设计方法与校验标准.md` | 参数范围、校验标准查不到依据 |
| `设计说明书_23044401.md` | 少了对照样例（建议留着） |

**安装步骤：**

1. 打开仓库页面 https://github.com/cly0301/TUSTER-help-hgyl
2. 点绿色的 **Code** 按钮 → **Download ZIP**
3. 解压，会得到一个 `TUSTER-help-hgyl-main` 文件夹
4. 进去，把里面的 **`chemeng-distillation-design` 文件夹整体**复制到你的 DSH 预设目录：

   ```
   C:\Users\<你的用户名>\.dsh\.agent-presets\<你的预设名>\skills\
   ```

   放好之后，目录结构应当长这样（对照检查一下，缺文件就会出问题）：

   ```
   .agent-presets\<预设名>\skills\chemeng-distillation-design\
       ├── SKILL.md
       ├── README.md
       ├── 14429 设计说明书107.pdf
       ├── 设计说明书_23044401.md
       └── resources\
           ├── 模板原文_14429.txt
           ├── 课件要点_设计方法与校验标准.md
           ├── design_calc.py
           └── ethanol-water-vle.csv
   ```

5. 重启 DSH（或新开一个会话），在预设里选「化工原理课设助手」就能用了。

> 这个 skill 是**自包含**的，装好以后不再需要任何外部文件。

## 三、怎么用（最方便：在 DSH 里用）

1. 打开 DSH，**新开一个会话**。
2. 在预设（preset）选择里，选 **「化工原理课设助手」**。
3. 在对话框里直接说，比如：

   > 帮我做乙醇-水筛板精馏塔课程设计，学号 23044401

4. 它会自动：
   - 拆出你的「班号后三位」「学号后两位」
   - 问你几个要自己选的参数（比如板间距、筛孔大小……），**每一项都会给推荐值，你直接选推荐就行**
   - 最后生成完整《设计说明书》和《装配图绘制指导》

5. 如果它问参数时，你**不确定就选「推荐」**——那是最稳妥的正确值。

## 四、怎么用（备用：直接跑计算脚本）

脚本一次跑完全部计算（2.1 物料衡算 到 2.13 接管管径），末尾会自动给出**校核结论**。若有指标不合格，它会**直接算出该改成多少**——例如「孔距 t：14 → 17 mm；试算：稳定系数 2.10/1.63、全塔压降 23.5 kPa —— 全部合格」，照着改参数再跑一次即可。如果你只是想快速看计算结果，不用开 DSH：

1. 打开「命令提示符」或 PowerShell。
2. 进入 skill 目录（把下面的路径换成你实际存放这个 skill 的目录）：

   ```
   cd <skill所在目录>\chemeng-distillation-design
   ```

3. 输入下面命令（把学号换成你的）：

   ```
   python resources\design_calc.py --id 23044401
   ```

4. 屏幕上就会打印出全部计算结果。

**三种写法任选一种：**

| 你想怎么输入 | 命令 |
|---|---|
| 只给学号 | `python resources\design_calc.py --id 23044401` |
| 学号 + 班号 | `python resources\design_calc.py --id 23044401 --banhao 445` |
| 直接给后两位/后三位 | `python resources\design_calc.py --xuehao 01 --banhao 445` |

> 说明：只给学号时，会自动按「前3位+班号3位+学号2位」拆出班号。例如 `23044401` 拆成班号 `444`、学号 `01`。
>
> 学号拆解规则的完整说明以 `SKILL.md` 第 0 节为准。

## 六、常见问题

**Q1：学号和班号是什么关系？**
学号一般 8 位，拆成「前3位 + 班号3位 + 学号2位」。例如 `23044401` = 前3位`230` + 班号`444` + 学号`01`。如果你学校的规定不一样（班号是独立数字），就用 `--banhao` 单独填。

**Q2：它问的参数我不会选怎么办？**
一律选「推荐」。推荐值都是教材标准值，最稳妥。

**Q3：跑脚本报错怎么办？**
确认 Python 已安装（在命令行输入 `python --version` 能看到版本号）。确认命令行当前目录是对的（上面第四节的第 2 步）。

**Q4：理论板数和别人不一样？**
图解法数理论板有 ±1~2 块的读图误差，是正常的。以你自己图上的为准，脚本用于核对数量级。

**Q5：只把 `SKILL.md` 复制到 skills 目录行不行？**
不行。`SKILL.md` 只是「指令书」，计算脚本、模板原文、气液平衡数据都在同目录的 `resources\` 里，少了任何一个都跑不起来。必须把 `chemeng-distillation-design` **整个文件夹**放进去，详见上面第二节。

**Q6：装好之后还要联网吗？**
不用。这个 skill 是自包含的，所有文件都在文件夹里。
