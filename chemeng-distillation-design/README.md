# 化工原理课程设计助手 · 使用说明（小白版）

这是一份**「乙醇-水筛板精馏塔」课程设计**的自动助手。你只要告诉它你的学号，它就会帮你：

- 把学号换成设计参数（进料/塔顶/塔釜浓度、回流比）
- 一项一项问你「要自己选的设计参数」，并给出推荐值
- 自动算出全部结果（物料衡算 → 回流比 → 理论/实际塔板数 → 塔径 → 塔板结构 → 流体力学校核 → 负荷性能图 → 塔高 → 冷凝器 → 五种接管管径）
- 生成一份能照着抄的《设计说明书》
- 生成一份「装配图绘制指导」（告诉你画装配图要用的所有数据）

---

## 一、你需要准备什么

1. 一台能联网的电脑（Windows）
2. 装好 **Python**（用来跑计算脚本，可选）
3. 已经装好 **DeepSeek Harness（DSH）**（用来加载这个 skill）

> 如果你只会在 DSH 里聊天，Python 可以不装——计算脚本只是备用的复核工具。

---

## 二、怎么用（最方便：在 DSH 里用）

1. 打开 DSH，**新开一个会话**。
2. 在预设（preset）选择里，选 **「化工原理课设助手」**。
3. 在对话框里直接说，比如：

   > 帮我做乙醇-水筛板精馏塔课程设计，学号 23044401

4. 它会自动：
   - 拆出你的「班号后三位」「学号后两位」
   - 问你几个要自己选的参数（比如板间距、筛孔大小……），**每一项都会给推荐值，你直接选推荐就行**
   - 最后生成完整《设计说明书》和《装配图绘制指导》

5. 如果它问参数时，你**不确定就选「推荐」**——那是最稳妥的正确值。

---

## 三、怎么用（备用：直接跑计算脚本）

脚本一次跑完全部计算（2.1 物料衡算 到 2.13 接管管径），末尾会自动给出**校核结论**。若有指标不合格，它会**直接算出该改成多少**——例如「孔距 t：14 → 17 mm；试算：稳定系数 2.10/1.63、全塔压降 23.5 kPa —— 全部合格」，照着改参数再跑一次即可。如果你只是想快速看计算结果，不用开 DSH：

1. 打开「命令提示符」或 PowerShell。
2. 进入 skill 目录（把下面的路径换成你实际存放这个 skill 的目录）：

   ```
   cd <skill所在目录>\chemeng-distillation-design
   ```

3. 输入下面命令（把学号换成你的）：

   ```
   python resources\design_calc.py --id 23044401
   ```

4. 屏幕上就会打印出全部计算结果。

**三种写法任选一种：**

| 你想怎么输入 | 命令 |
|---|---|
| 只给学号 | `python resources\design_calc.py --id 23044401` |
| 学号 + 班号 | `python resources\design_calc.py --id 23044401 --banhao 445` |
| 直接给后两位/后三位 | `python resources\design_calc.py --xuehao 01 --banhao 445` |

> 说明：只给学号时，会自动按「前3位+班号3位+学号2位」拆出班号。例如 `23044401` 拆成班号 `444`、学号 `01`。
>
> 学号拆解规则的完整说明以 `SKILL.md` 第 0 节为准。

## 五、常见问题

**Q1：学号和班号是什么关系？**
学号一般 8 位，拆成「前3位 + 班号3位 + 学号2位」。例如 `23044401` = 前3位`230` + 班号`444` + 学号`01`。如果你学校的规定不一样（班号是独立数字），就用 `--banhao` 单独填。

**Q2：它问的参数我不会选怎么办？**
一律选「推荐」。推荐值都是教材标准值，最稳妥。

**Q3：跑脚本报错怎么办？**
确认 Python 已安装（在命令行输入 `python --version` 能看到版本号）。确认命令行当前目录是对的（上面第三节第 2 步）。

**Q4：理论板数和别人不一样？**
图解法数理论板有 ±1~2 块的读图误差，是正常的。以你自己图上的为准，脚本用于核对数量级。
