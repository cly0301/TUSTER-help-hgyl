### 校验规则（必须遵守）

使用者选的值**若超出可行范围、或不能满足设计要求**，**必须立即提醒使用者**，说明为什么不合格、后果是什么，让使用者改回可行值；**不要强行进入下一步演算**（否则后续偏差越滚越大）。典型需要拦截的情况：

- **u/uF 取 0.5**：0.5 只用于发泡严重液体，乙醇-水非强发泡，取 0.5 会使塔径比 0.8 时大 约40%（如 1.0→1.4 m）、设备费大增 → 提醒「建议 0.7到0.8」。
- **hL 低于 50 mm**：低于常用下限，会使堰高 hw 过小、或无法同时满足「how>6 mm 且 hw 合理」→ 提醒「建议 ≥50 mm」。
- **d0 超出 3到8 mm、t/d0 超出 2.5到5**：开孔率/漏液/雾沫夹带会失控 → 提醒改回。
- **hH 不满足 20 < hH < hw−(5到10)**：无法形成液封或液体流不出 → 提醒改回。

## 4. 说明书各章内容（固定文字 + 可变计算）

### 第一章 概述（照抄模板原文）

**1.1 精馏操作对塔设备的要求**：精馏是气液两相传质，塔设备须使气液充分接触以达到较高传质效率，并满足：①气液处理量大而不发生雾沫夹带/拦液/液泛；②操作稳定、弹性大；③流体阻力（压降）小；④结构简单、材料耗用量小、制造安装容易；⑤耐腐蚀、易堵塞、方便操作检修；⑥塔内滞留量小。实际上，任何塔设备都难以满足上述所有要求，且有些要求互相矛盾，不同塔型各有独特优点，设计时应按物系性质抓住主要矛盾进行选型。

**1.2 板式塔类型**：气液传质设备分板式塔和填料塔，本设计只讨论板式塔。板式塔按气液接触元件分泡罩塔、浮阀塔、筛板塔等，目前主要塔型为浮阀塔与筛板塔。
- **筛板塔**：优点：结构简单、造价约为泡罩塔60%/浮阀塔80%、处理能力大（比泡罩塔高10到15%）、塔板效率高（比泡罩塔高15%）、压降低（每板比泡罩塔低30%）。缺点：安装水平度要求高、操作弹性较小（约2到3）、小孔易堵。
- **浮阀塔**：优点：浮阀随气量上下浮动自动调节、处理能力大（比泡罩塔高20到40%）、操作弹性大（5到9）、塔板效率高、压降小。缺点：结构比筛板复杂、造价为筛板塔的120到130%。
**本次设计选用筛板塔**（结构简单、造价低、压降低；乙醇-水对操作弹性要求不高，筛板塔能满足）。

**1.3 精馏塔设计步骤**：①设计方案确定和说明；②蒸馏塔工艺计算（塔高塔径）；③塔板设计（工艺尺寸、流体力学验算、接管、泵）；④管路及附属设备计算选型（冷凝器）；⑤抄写说明书；⑥绘制工艺流程图和精馏塔设备图。

### 第二章 设计方案的确定（照抄模板原文）

**2.1 操作条件的确定**（按以下固定论述，只把参数填入）：

- **操作压力**：物性无特殊要求时一般在稍高于大气压下操作，本设计取**常压（101.3 kPa）**。
- **进料状态**：一般将料液预热到泡点送入塔中（操作易控制、不受季节气温影响），本设计取**泡点进料（q=1）**。
- **加热方式**：蒸馏釜通常用**间接蒸汽加热**（设再沸器）；但当塔底产物近于纯水、浓度稀薄时相对挥发度大（如酒精-水），可用**直接蒸汽加热**：优点：可用较低压力蒸汽、釜内只装鼓泡管不设庞大传热面、省操作费和设备费；缺点：蒸汽通入对塔底溶液起稀释作用、塔板数稍增，但稀薄时增加不多，故合适。加热蒸汽压力须高于釜压以克服小孔阻力与液柱静压（酒精水溶液一般 0.4到0.7 kPa 表压）。饱和水蒸汽冷凝潜热大、价廉，常用作加热剂。本设计取**直接蒸汽加热**。
- **冷却剂与出口温度**：塔顶蒸汽温度低，可用常温水冷却，最经济；出口温度一般不超过 50℃（否则水垢析出）。本设计冷却水 30→45℃。
- **热能的利用**：精馏是反复汽化冷凝的耗能过程，节约热能很重要。选取适宜回流比使能耗最低；不计进料/馏出液/釜液焓差时，塔顶冷凝器输出热量近似等于塔底输入热量（数量可观，多被冷却剂带走损失）。可用**釜液预热原料、塔顶蒸汽冷凝潜热加热低能级物料**来回收余热。

**2.2 精馏流程示意图**：连续精馏。乙醇-水溶液经卧式列管换热器预热后送入精馏塔；塔顶上升蒸汽经列管式全凝器冷凝后入回流罐，部分回流、其余作塔顶产品经冷却器冷却送贮槽；塔釜直接蒸汽供热，塔底产品经冷却送贮槽。

**2.3 确定设计方案的原则**：总原则是在可能条件下尽量采用先进技术，使生产技术上最先进、经济上最合理，符合优质、高产、安全、低消耗。
- ①**满足工艺和操作要求**：保证产品达到任务要求且质量稳定（各流体流量、压头、温度、状态稳定）；有一定操作弹性（设调节阀、备用支线）；设置必需仪表（温度计、压强计、流量计）。
- ②**满足经济要求**：节省热能和电能、减少设备及基建费用（利用塔顶塔底废热、选好回流比和冷却水出口温度）。
- ③**保证安全生产**：易燃物料不能泄漏、常压塔需设安全装置防超压或真空破坏。
课设中对①多考虑、②定性考虑、③一般考虑。

### 第三章 精馏塔的工艺计算（公式固定，数值随学号/班号变，以下为学号23044401→班号444/学号01的实例）

**3.1 物料衡算**
- 摩尔分率：xF=0.1998、xD=0.8496、xW=0.00118
- 平均摩尔质量：MF=23.59、MD=41.79、MW=18.03 kg/kmol
- 进料泡点温度（插值）：tF≈83.2℃，q=1
- 最小回流比（切线法，从 (xD,xD) 作平衡线切线）：切点 (0.741,0.780)，`Rmin = xD/ym − 1 = 1.81`；`R = 1.41×1.81 = 2.55`
- 直接加热物料衡算：`D=24×1000/24/MD = 23.93 kmol/h`；`S=(R+1)D = 84.90 kmol/h`；`F = [D(xD−xW)+S·xW]/(xF−xW) = 102.23 kmol/h`；`W=F−D+S=163.20 kmol/h`；核算 `xW*=(FxF−DxD)/W=0.00056`（提馏段操作线过 (xW*,0)）

**3.2 理论塔板数（图解法）**
- 查表记录常压下乙醇-水 t-x-y 平衡数据（见 `ethanol-water-vle.csv`）
- 精馏段操作线 `y=R/(R+1)·x + xD/(R+1) = 0.7182x+0.2395`；q 线 x=xF；提馏段操作线过 (xW*,0)
- 从 (xD,xD) 起步进阶梯，直接蒸汽画到 x≤xW*：**理论级数 27（含塔釜），理论板 N=26（精馏段23、提馏段3）**

**3.3 操作条件及物性估算**
- 操作温度：t1≈78.2℃（塔顶）、tF≈83.2℃（进料）、tW≈99.5℃（塔釜）；精馏段平均 80.7℃、提馏段平均 91.4℃、全塔平均 88.9℃
- 平均摩尔质量：液相/气相按各板组成算（精馏段 ML=41.5、MV=41.8；提馏段 ML=18.0、MV≈32.9）
- 液相平均粘度：`μ混^(1/3) = Σ xi·μi^(1/3)`（乙醇/水粘度查手册插值），全塔平均 μL≈0.33 mPa·s
- 相对挥发度：逐板 `αi = yi(1−xi)/[xi(1−yi)]`，取几何平均 αm≈1.9
- 总板效率（O'Connell + 筛板修正 1.1）：`ET = 1.1×0.49(αm·μL)^(−0.245) ≈ 0.60`
- 实际板数：精馏段 23/0.60≈38 块、提馏段 3/0.60≈6 块，**总实际板 Ne=44**（加料板在第 39 块附近）
- 操作压力：每板压降约 0.7 kPa，塔釜表压约 18到20 kPa

**3.4 气液相负荷**
- 精馏段：`L=RD=61.2 kmol/h`、`V=(R+1)D=84.9 kmol/h`；提馏段：`L'=L+F=163.2 kmol/h`、`V'=S=84.9 kmol/h`

**3.5 工艺尺寸**
- 泛点气速 `uF=C√((ρL−ρG)/ρG)`，C=C20(σ/20)^0.2（C20 查 Smith 图，按板间距 HT）
- 空塔气速 `u=0.8uF`；有效面积 `An=V/u`；塔截面积 `A=An/(1−Ad/A)`；`D=√(4A/π)`
- 结果：精馏段 D=0.90→**1.0 m**，提馏段 D=0.72→0.8 m（统一用 1.0 m）
- 塔有效高度 `HE=(Ne精−1)HT + (Ne提−1)HT'`

**3.6 塔板设计**
- 溢流装置：lw=0.7D=700 mm；堰上液头 `how=0.0028Fw(L/lw)^(2/3)`（Fw=1.02）；hL=hw+how=50 mm → hw≈40 mm；降液管底隙 hH=30 mm
- 筛板：d0=5 mm、t=14 mm（正三角形）、φ=0.907(d0/t)²=0.116；鼓泡区 Aa、开孔区 A0=φAa、孔数 `n=1.155Aa/t²`、孔速 `u0=V/A0`

**3.7 流体力学验算**
- 单板压降 `ΔHt=h0+he`，`h0=(1/2g)(u0/C0)²(ρV/ρL)`、`he=β(hw+how)`；全塔压降 `N·ΔHt·ρL·g ≤30 kPa`
- 降液管液面 `Hd=hL+hd+ΔHt ≤ φ(HT+hw)`；停留时间 `τ=Hd·Ad/VL >3 s`
- 雾沫夹带（Hunt）`eV=(0.0057/σ)[u/(HT−2.5hL)]^3.2 <0.1`
- 漏液 `u0,min=C0√(2g·h0,min·ρL/ρV)`，稳定系数 `u0/u0,min >1.5`

**3.8 塔板负荷性能图**
- 五条线（漏液/液泛/雾沫夹带/液相上下限）+ 操作点 + 操作线；操作弹性 2到3、稳定系数 >1.5
