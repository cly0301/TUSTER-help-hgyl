# 乙醇-水筛板精馏塔课程设计

本 skill 用于**化工原理课程设计**中「乙醇-水体系筛板精馏塔」的设计。产出物是**可手写抄录的《设计说明书》完整内容**（七章 + 符号说明 + 参考文献）。

## 执行流程（严格按此顺序，不要跳步）

**第 1 步 · 确认任务**：要到使用者的学号，按第 0 节换算出 aF / aD / aW 与回流比系数。

**第 2 步 · 参数问询 + 逐组核算（不可跳过）**：按第 2 节**逐组询问**，每组都给出「最佳建议值」和「可行范围」。**每得到一组答复，立刻跑一次增量核算**（见 2.3），把「这个选择对整体设计的影响」和「后续参数的可行范围」讲给使用者听，再用新的范围问下一组。**在全部参数定下来之前，不要开始写说明书。**

**第 3 步 · 完整校核**：参数全部定下来后跑一次完整计算出报告（第 2 步的 `--advise` 已逐组核算过，这里是最终确认）：

```
python resources/design_calc.py --id 23044401 --set HT=0.35 HT2=0.65 lw_ratio=0.7 t=17 u_uF=0.8
```

- 参数名对应：`HT`/`HT2`（板间距 m）、`lw_ratio`、`hL`、`hH`、`Wc`、`Ws`、`d0`、`t`、`tp`、`u_uF`、`hole_every`、`HD`/`HB`/`HS`、`u_liq`/`u_liq_ret`/`u_gas`、`K_cond`、`t_cool_in`/`t_cool_out`
- `--show-params` 可列出全部参数及当前值
- 报告开头会回显本次使用的自选参数，核对无误再看结论

**末尾结论必须是「全部合格」**——否则不要写说明书，回到第 2 步继续调参数。

**第 4 步 · 出说明书**：**以模板原文为底稿**——描述性文字保留，数据相关的表述替换（规则见第 3 节）。

**第 5 步 · 装配图绘制指导**：按第 5 节输出。

## 1. 参数换算（学号 → 设计浓度）

设 `学号后两位=a`、`班号后三位=b`（0到1 小数）：

| 参数 | 公式 |
|---|---|
| 进料质量分数 aF | `(30 + b×0.02 + a×0.05)/100` |
| 塔顶质量分数 aD | `(93.5 + a×0.02)/100` |
| 塔釜质量分数 aW | `0.003`（固定） |
| 产量 | 24 吨/天（固定） |
| 回流比系数 | `1.4 + a×0.01`（R=该系数×Rmin） |

质量→摩尔：`x = (a/46) / (a/46 + (1-a)/18)`（乙醇 M=46，水 M=18）。

> 本实例（学号后两位 01、班号后三位 444）：aF=38.93%、aD=93.52%、aW=0.3%；xF=0.1996、xD=0.8496、xW=0.00118。

## 2. 自选参数问询（**必须先问，问完才算**）

设计变量个数多于方程个数，多出来的那部分（板间距、孔径、堰长……）**必须由设计者从经验范围里选定**。这是使用者的权利，不是你的——你的任务是：**把选择权交给他，同时告诉他哪个值最好、调大调小各有什么后果。**

### 2.1 提问格式（每组都按这个格式问）

```
【第 N 组：组名】
· 最佳建议值：<值>          ← 教材标准值，不确定就选它
· 可行范围：<下限> ~ <上限>
· 影响：<调大怎样、调小怎样>
你要自己定，还是用建议值？
```

**节奏**：
- 第 1~5 组（影响最大的）**逐组问**，等使用者回答后再问下一组；
- 第 6 组一次列完，让使用者一并确认；
- 使用者说「都用推荐值」→ 立即停止问询，全部采用建议值。

### 2.2 逐组问询清单

**第 1 组 · 板间距 HT**（影响塔高、液沫夹带、压降，最关键）
- 最佳建议值：精馏段 **350 mm**、提馏段 **650 mm**
- 可行范围：300 ~ 600 mm
- 影响：加大板间距 → 塔变高、造价升，但液沫夹带减小、操作弹性增大；减小则相反

**第 2 组 · 空塔气速系数 u/uF**（直接决定塔径）
- 最佳建议值：**0.8**
- 可行范围：0.5 ~ 0.8（只有发泡液体才取 0.5~0.6）
- 影响：系数越小塔径越大。取 0.5 会让塔径比 0.8 时大约 40%（如 1.0 → 1.4 m），设备费大增

**第 3 组 · 筛孔直径 d0 与孔距 t**（决定开孔率与孔速）
- 最佳建议值：d0 = **5 mm**、t = **17 mm**（t/d0 = 3.4，开孔率约 7.8%）
- 可行范围：d0 取 3 ~ 8 mm；t 取 (2.5 ~ 5)·d0
- 影响：孔距过小 → 开孔率偏大 → 孔速偏低 → 稳定系数不足、容易漏液；孔距过大 → 鼓泡不均匀

**第 4 组 · 堰长比 lw/D**
- 最佳建议值：**0.7**
- 可行范围：0.6 ~ 0.8
- 影响：堰长决定降液管面积，进而影响液体停留时间与堰上液头

**第 5 组 · 板上清液层 hL**
- 最佳建议值：**50 mm**
- 可行范围：50 ~ 80 mm
- 影响：hL 越大 → 堰高越大、液层阻力越大 → 单板压降与液沫夹带上升、稳定系数下降

**第 6 组 · 其余参数**（一次列出，用推荐值即可）

| 参数 | 建议值 | 可行范围 |
|---|---|---|
| 降液管底隙 hH | 28 mm | 20 < hH < hw−(5到8) |
| 边缘区 Wc / 安定区 Ws | 50 / 60 mm | 25到75 / 50到100 mm |
| 板厚 tp | 4 mm | 3到4 mm |
| 人孔 | 每 6 块一个（Φ600） | 每 6到8 块一个 |
| 塔顶空间 HD / 塔底 HB / 裙座 HS | 1.0 / 1.0 / 1.5 m | HD 1到1.2、HB≈1、HS 1.5 |
| 进料板间距 HF | 1.05 m | 进料板兼设人孔 |
| 全凝器 K / 冷却水 | 915 / 30→45℃ | K 580到1160、出水≤50℃ |
| 液体流速 / 气体流速 | 0.5 / 15 m/s | 液体 0.3到1.5、气体 10到15 |

> 查图系数 Fw / C0 / β / φ 分别取 1.02 / 0.82 / 0.6 / 0.6，属查图结果，**不用问使用者**。

### 2.3 每组答复后立刻核算（关键步骤）

**每得到一组参数，马上传给脚本做增量核算**，不要等全部问完：

```
python resources/design_calc.py --id <学号> --set <目前已定的全部参数> --advise
```

例如使用者定了板间距 400 mm：

```
python resources/design_calc.py --id 23044401 --set HT=0.4 --advise
```

输出分两部分，**都要转达给使用者**：

**①【对整体设计的影响】** —— 这个选择让哪些指标变了、变了多少：

```
精馏段塔径  0.904 m → 0.961 m  （↑0.057 m, +6.3%）
圆整塔径    1.0 m   （不变）
全塔压降    23.52 kPa  （不变）
稳定系数(精) 2.10  （不变）
```

要讲清**为什么**：参数之间是有连锁的。例如板间距会通过 Smith 关联图影响泛点气速 → 改变塔径 → 塔径又影响孔速与压降（塔径变小则孔速升高、压降上升）。所以不能只说"板间距变大塔变高"，要照实说清它牵动了什么。

**②【后续参数建议】** —— 每个还没定的参数，在当前选择下的**可行范围**：

```
HT2       提馏段板间距   现值 0.65 m   可行 0.3 ~ 0.9 m
lw_ratio  堰长比 lw/D    现值 0.7      可行 0.65 ~ 0.8
hL        板上清液层     现值 50 mm    可行 40 ~ 60 mm
```

把这个范围当作**下一组参数的推荐区间**，替代 2.2 表格里的默认范围。

**若核算结论是「不合格」**：不要继续往下问。先把脚本给出的建议值转达使用者，让他调整这一组或上一组的参数，直到合格再进入下一组。

### 2.4 校验规则（必须遵守）

使用者选的值**若超出可行范围、或不能满足设计要求**，**必须立即提醒使用者**，说明为什么不合格、后果是什么，让使用者改回可行值；**不要强行进入下一步演算**（否则后续偏差越滚越大）。典型需要拦截的情况：

- **u/uF 取 0.5**：0.5 只用于发泡严重液体，乙醇-水非强发泡，取 0.5 会使塔径比 0.8 时大 约40%（如 1.0→1.4 m）、设备费大增 → 提醒「建议 0.7到0.8」。
- **hL 低于 50 mm**：低于常用下限，会使堰高 hw 过小、或无法同时满足「how>6 mm 且 hw 合理」→ 提醒「建议 ≥50 mm」。
- **d0 超出 3到8 mm、t/d0 超出 2.5到5**：开孔率/漏液/雾沫夹带会失控 → 提醒改回。
- **hH 不满足 20 < hH < hw−(5到8)**：无法形成液封或液体流不出 → 提醒改回。

> **参数全部选定后，务必让脚本跑一遍校核**。脚本会对两段各做六项流体力学校核，**若有不合格项，输出末尾会直接给出建议参数值并用完整试算验证**（形如「孔距 t：14 → **17 mm**；试算：稳定系数 2.10/1.63、全塔压降 23.5 kPa —— 全部合格」）。把建议值转达给使用者，确认后改参数重跑，直到结论变为「全部合格」再写进说明书。

### 第三章 精馏塔的工艺计算（公式固定，数值随学号/班号变，以下为学号23044401→班号444/学号01的实例）

**3.1 物料衡算**
- 摩尔分率：xF=0.1996、xD=0.8496、xW=0.00118
- 平均摩尔质量：MF=23.59、MD=41.79、MW=18.03 kg/kmol
- 进料泡点温度（插值）：tF≈83.3℃，q=1
- 最小回流比（切线法，从 (xD,xD) 作平衡线切线）：切点 (0.741,0.780)，**切线在 y 轴上的截距 ym=0.3027**（即 `ym = xD/(Rmin+1)`）；`Rmin = xD/ym − 1 = 0.8496/0.3027 − 1 = 1.81`；`R = 1.41×1.81 = 2.55`
- 直接加热物料衡算：`D=1000/MD = 23.93 kmol/h`；`S=(R+1)D = 84.90 kmol/h`；`F = [D(xD−xW)+S·xW]/(xF−xW) = 102.80 kmol/h`；`W=F−D+S=163.77 kmol/h`；核算 `xW*=(FxF−DxD)/W=0.00118`（**恒等于 xW**，提馏段操作线过 (xW*,0)）

**3.2 理论塔板数（图解法）**
- 查表记录常压下乙醇-水 t-x-y 平衡数据（见 `ethanol-water-vle.csv`）
- 精馏段操作线 `y=R/(R+1)·x + xD/(R+1) = 0.7182x+0.2395`；q 线 x=xF；提馏段操作线过 (xW*,0)
- 从 (xD,xD) 起步进阶梯，直接蒸汽画到 x≤xW*：**理论级数 26（含塔釜），理论板 N=25（精馏段23、提馏段3）**

**3.3 操作条件及物性估算**
- 操作温度：t1≈78.2℃（塔顶）、tF≈83.2℃（进料）、tW≈99.5℃（塔釜）；精馏段平均 80.7℃、提馏段平均 91.4℃、全塔平均 88.9℃
- 平均摩尔质量：液相/气相按各板组成算（精馏段 ML=41.5、MV=41.8；提馏段 ML=18.0、MV≈32.9）
- 液相平均粘度：`μL = μA·xF + μB·(1−xF)`（**以进料 xF 为基准、在全塔平均温度下线性加和**，乙醇/水粘度查手册插值），全塔平均 μL≈0.33 mPa·s
- 相对挥发度：逐板 `αi = yi(1−xi)/[xi(1−yi)]`，取几何平均 αm≈1.81
- 总板效率（O'Connell + 筛板修正 1.1）：`ET = 1.1×0.49(αm·μL)^(−0.245) ≈ 0.61`
- 实际板数（**两段分别向上取整后相加**）：精馏段 23/0.61≈37.6→**38 块**、提馏段 3/0.61≈4.9→**5 块**，**总实际板 Ne=43**（加料板在第 39 块附近）
- 操作压力（3.3.7）：塔釜表压取 **18~20 kPa**（工业上酒精精馏塔的常规值；设计要求不高于 30 kPa）
- 平均密度（3.3.8）：气相 `ρV = P·M_V/(RT)`、液相按摩尔体积加和；本实例 精馏段 ρV=1.449、ρL=755.9 kg/m³；提馏段 ρV=1.323、ρL=864.4 kg/m³
- 平均表面张力（3.3.9）：按等张比容法 `σ = (P_m/V_m)⁴`（P_m 按摩尔分率加和，V_m 摩尔体积 cm³/mol）；本实例 精馏段 σ=17.95、提馏段 σ=22.34 mN/m

**3.4 气液相负荷**
- 精馏段：`L=RD=61.0 kmol/h`、`V=(R+1)D=84.90 kmol/h`；提馏段：`L'=RD+F=163.77 kmol/h`、`V'=S=84.90 kmol/h`（恒摩尔流下 `L'=W`）

**3.5 工艺尺寸**
- 泛点气速 `uF=C√((ρL−ρG)/ρG)`，C=C20(σ/20)^0.2（C20 查 Smith 图，按板间距 HT）
- 空塔气速 `u=0.8uF`；有效面积 `An=V/u`；塔截面积 `A=An/(1−Ad/A)`；`D=√(4A/π)`
- 塔径圆整：**≤1000 mm 按 100 mm 递增，>1000 mm 按 200 mm 递增**；两段塔径不同时用精馏段塔径统一（不设异径塔）
- 结果：精馏段 D=0.90→**1.0 m**，提馏段 D=0.72→0.8 m（统一用 1.0 m）
- 塔有效高度 `HE=(Ne精−1)HT + (Ne提−1)HT' + 人孔加高`（每个人孔处板间距增加 600 mm）

**3.6 塔板设计**
- 溢流装置：lw=0.7D=700 mm；堰上液头 `how=0.0028Fw(L/lw)^(2/3)`（Fw=1.02）=8.1 mm（>6 mm ✓）；`hL=hw+how=50 mm` → hw=41.9 mm；降液管底隙 hH=28 mm
- 降液管（弓形）：宽 Wd=143 mm、面积 Ad=0.0689 m²、Ad/A=0.0877
- 筛板：d0=5 mm、t=17 mm（正三角形）、`φ=0.907(d0/t)²=0.0785`；鼓泡区 Aa=0.4928 m²；开孔区 `A0=φAa`=0.0387 m²；孔数 `n=1.155Aa/t²`=1969；孔速 `u0=V/A0`：精馏段 17.59、提馏段 15.15 m/s；板厚 tp=4 mm

**3.7 流体力学验算**（**精馏段、提馏段各算一套**）
- 单板压降 `ΔHt=h0+he`，`h0=(1/2g)(u0/C0)²(ρV/ρL)`、`he=β(hw+how)`；降液管阻力 `hd=0.153[VL/(lw·hH)]²`
- 本实例：精馏段 ΔHt = 44.95+30.00 = **74.95 mm 液柱**；提馏段 = 26.62+30.00 = **56.62 mm 液柱**；**全塔压降 23.52 kPa**（≤30 kPa ✓）
- 降液管液面 `Hd=hL+hd+ΔHt ≤ φ(HT+hw)`：精馏段 125.30 ≤ 235.11 ✓；提馏段 107.24 ≤ 414.10 ✓
- 停留时间 `τ=Ad·Hd/VL >3 s`：精馏段 9.22 s ✓；提馏段 5.95 s ✓
- 雾沫夹带（Hunt）`eV=(0.0057/σ)[u/(HT−2.5hL)]^3.2 <0.1`：精馏段 0.0318 ✓；提馏段 0.0011 ✓
- 漏液：`h0,min=0.0056+0.13(hw+how)−hσ`、`hσ=4×10⁻³σ/(ρL·g·d0)`，`u0,min=C0√(2g·h0,min·ρL/ρV)`，稳定系数 `u0/u0,min >1.5`：精馏段 K=2.10 ✓；提馏段 K=1.63 ✓

**3.8 塔板负荷性能图**（**精馏段、提馏段各画一张**；手算时各线视为直线，取两个 (V_L, V_V) 点即可作图）
- 五条线：①漏液线（气相下限，`u0,min·A0`）②雾沫夹带线（令 eV=0.1 反解 u）③液泛线（令 `Hd=φ(HT+hw)` 反解）④液相下限线（how=6 mm）⑤液相上限线（τ=3 s）；再画操作点与操作线
