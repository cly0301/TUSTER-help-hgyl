## 第一章 概述

### 1.1 精馏操作对塔设备的要求
精馏是气液两相传质过程，塔设备须使气液两相充分接触以达到较高的传质效率，并满足：①气液处理量大而不发生雾沫夹带/拦液/液泛；②操作稳定、弹性大；③流体阻力（压降）小；④结构简单、材料耗用量小、制造安装容易；⑤耐腐蚀、易堵塞、方便操作检修；⑥塔内滞留量小。不同塔型各有优点，设计时按物系性质选型。

### 1.2 板式塔类型
气液传质设备分板式塔和填料塔。板式塔按气液接触元件分泡罩塔、浮阀塔、筛板塔等。筛板塔优点：结构简单、造价约为泡罩塔 60%/浮阀塔 80%、处理能力大、塔板效率高、压降低；缺点：安装水平度要求高、操作弹性较小（2到3）、小孔易堵。**本次设计选用筛板塔。**

### 1.3 精馏塔设计步骤
①设计方案确定和说明；②蒸馏塔工艺计算；③塔板设计（工艺尺寸、流体力学验算）；④管路及附属设备计算选型；⑤抄写说明书；⑥绘制工艺流程图和精馏塔设备图。

## 第二章 设计方案的确定

### 2.1 操作条件的确定
- **操作压力**：物性无特殊要求时一般在稍高于大气压下操作，本设计取**常压（101.3 kPa）**。
- **进料状态**：料液预热到泡点送入塔中，本设计取**泡点进料（q=1）**。
- **加热方式**：塔底产物近于纯水、浓度稀薄时相对挥发度大（如酒精-水），宜用**直接蒸汽加热**：釜内只装鼓泡管、不设庞大传热面，省设备费。
- **冷却剂与出口温度**：塔顶蒸汽温度低，用常温水冷却；出口温度不超过 50℃。本设计冷却水 30→45℃。
- **热能的利用**：选取适宜回流比使能耗最低。

### 2.2 精馏流程示意图
连续精馏。乙醇-水溶液经卧式列管换热器预热后送入精馏塔；塔顶上升蒸汽经列管式全凝器冷凝后入回流罐，部分回流、其余作塔顶产品；塔釜直接蒸汽供热，塔底产品排出。

### 2.3 确定设计方案的原则
①满足工艺和操作要求；②满足经济要求；③保证安全生产。

## 第三章 精馏塔的工艺计算

### 3.1 物料衡算

**3.1.1 摩尔分率**（乙醇 M_A=46，水 M_B=18）

- 进料：`xF = (0.3948/46)/(0.3948/46 + 0.6052/18) = 0.2034`
- 塔顶：`xD = (0.9374/46)/(0.9374/46 + 0.0626/18) = 0.8542`
- 塔釜：`xW = (0.003/46)/(0.003/46 + 0.997/18) = 0.00118`

**3.1.2 平均摩尔质量**

- MF = 46×0.2034 + 18×0.7966 = **23.70 kg/kmol**
- MD = 46×0.8542 + 18×0.1458 = **41.92 kg/kmol**
- MW = 46×0.00118 + 18×0.99882 = **18.03 kg/kmol**

**3.1.3 进料热状况**：泡点进料，插值得 tF≈83.2℃，q=1。

**3.1.4 最小回流比（切线法）**

从 (xD,xD)=(0.8542,0.8542) 作平衡线切线，切点 (0.779, 0.804)，切线 y 轴截距 ym=0.2877：

```
Rmin = xD/ym − 1 = 0.8542/0.2877 − 1 = 1.97
R = 1.52 × Rmin = 1.52 × 1.97 = 2.99
```

**3.1.5 直接加热物料衡算**

- 塔顶产品：`D = 24000/24/MD = 1000/41.92 = 23.86 kmol/h`
- 加热蒸汽：`S = (R+1)D = (2.99+1)×23.86 = 95.26 kmol/h`
- 原料量：`F = [D(xD−xW) + S·xW]/(xF−xW) = 100.65 kmol/h`
- 釜液量：`W = F − D + S = 100.65 − 23.86 + 95.26 = 172.06 kmol/h`
- 釜液组成核算：`xW* = (F·xF − D·xD)/W = (100.65×0.2034 − 23.86×0.8542)/172.06 = 0.00052`

### 3.2 理论塔板数（图解法）

- 精馏段操作线：`y = R/(R+1)·x + xD/(R+1) = 0.7494x + 0.2140`
- q 线：x = xF = 0.2034；提馏段操作线过 (xW*, 0)
- 从 (xD,xD) 起步进阶梯，画到 x≤xW*：**理论级数 25（含塔釜），理论板 N = 24**（精馏段 21、提馏段 3）

### 3.3 操作条件及物性估算

- **操作温度**：塔顶 t1=78.22℃、进料 tF=83.2℃、塔釜 tW=99.51℃
- **液相平均粘度**：`μ混^(1/3) = Σ xi·μi^(1/3)`，全塔 μL≈0.330 mPa·s
- **相对挥发度**：逐板取几何平均 αm≈1.91
- **总板效率**：`ET = 1.1×0.49(αm·μL)^(−0.245) = 0.60`
- **实际板数**：精馏段 21/0.60≈34 块、提馏段 3/0.60≈6 块，**总实际板 Ne = 40**（加料板在第 35 块附近）
- **操作压力**：每板压降约 0.7 kPa，塔釜表压约 18到20 kPa

### 3.4 气液相负荷

- 精馏段：`L = RD = 2.99×23.86 = 71.4 kmol/h`；`V = (R+1)D = 95.26 kmol/h`
- 提馏段：`L' = L + F = 71.4 + 100.65 = 172.0 kmol/h`；`V' = S = 95.26 kmol/h`

### 3.5 工艺尺寸

- 泛点气速 `uF = C√((ρL−ρG)/ρG)`，C = C20(σ/20)^0.2（C20 查 Smith 图，按板间距 HT）
- 空塔气速 `u = 0.8uF`；`An = V/u`；`A = An/(1−Ad/A)`；`D = √(4A/π)`
- 结果：**精馏段 D = 0.96 → 1.0 m**；提馏段 D = 0.76 → 0.8 m（统一用精馏段 1.0 m）

### 3.6 塔板设计

- **溢流装置**：堰长 `lw = 0.65D = 650 mm`；堰上液头 `how = 0.0028×1.02×(3.96/0.65)^(2/3) = 9.5 mm`（>6 mm ✓）；板上清液层 hL=55 mm → 堰高 `hw = 55 − 9.5 = 45.5 mm`；降液管底隙 hH=30 mm
- **降液管**：宽 `Wd = R − √(R²−(lw/2)²) = 120 mm`；面积 `Ad = R²(θ−sinθ)/2 = 0.053 m²`（Ad/A≈0.068）
- **筛板**：d0=5 mm、t=14 mm（正三角形）、开孔率 `φ = 0.907(5/14)² = 0.116`；鼓泡区 `Aa = 0.52 m²`；开孔区 `A0 = φ·Aa = 0.061 m²`；孔数 `n = 1.155·Aa/t² ≈ 3081`；孔速 `u0 = V/A0 ≈ 12.6 m/s`；板厚 tp=4 mm

### 3.7 流体力学验算

- 单板压降 `ΔHt = h0 + he`，`h0 = (1/2g)(u0/C0)²(ρV/ρL)`（C0=0.82）、`he = β(hw+how)`（β=0.6）；全塔压降 ≤30 kPa
- 降液管液面 `Hd = hL + hd + ΔHt ≤ φ(HT+hw)`（φ=0.6）
- 停留时间 `τ = Hd·Ad/VL > 3 s`
- 雾沫夹带（Hunt）`eV = (0.0057/σ)[u/(HT−2.5hL)]^3.2 < 0.1`
- 漏液 `u0,min = C0√(2g·h0,min·ρL/ρV)`，稳定系数 >1.5

### 3.8 塔板负荷性能图

五条线 + 操作点 + 操作线；操作弹性 2到3、稳定系数 >1.5。

## 第四章 结果与结论

本设计对日产 24 吨 93.74% 乙醇的乙醇-水筛板精馏塔完成了全部工艺计算与校核。主要结果：理论板 24 块、实际板 40 块、塔径 1.0 m、全塔高约 22.4 m，各项校核均满足要求。

## 第五章 塔附件计算

- **接管**（五种）：进料管、回流管、塔底出料管、塔顶蒸汽出料管、塔底进气管，`d = √(4V/(πu))`（液速 0.3到0.5 m/s、气速 15 m/s）圆整到标准管
- **筒体封头**：筒体 DN1000×6、椭圆封头 DN1000×6
- **裙座**：Ø1000×6，高 1.5 m；**人孔**：Φ600，每 7 块塔板一个（共 5 个）
- **塔总体高度**：
  - 塔板段 = (34−1)×350 + (6−1)×650 + 进料板 1050 = 11,550 + 3,250 + 1,050 = 15,850 mm
  - 人孔加高 = 5 × 600 = 3,000 mm
  - 塔顶空间 1,000 + 塔底空间 1,000 + 裙座 1,500 mm
  - **H = 15,850 + 3,000 + 1,000 + 1,000 + 1,500 = 22,350 mm ≈ 22.4 m**
- **全凝器**：塔顶蒸汽潜热 r≈945.7 kJ/kg，热负荷 `QT = D(R+1)·r ≈ 1049 kW`；冷却水量 16.73 kg/s（30→45℃）；换热面积 `A = QT/(K·Δtm) ≈ 28.5 m²`（K=915）
- **原料预热器、进料泵、回流泵**：按负荷与扬程选型
