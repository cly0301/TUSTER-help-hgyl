## 第一章 概述

### 1.1 精馏操作对塔设备的要求
精馏是气液两相传质过程，塔设备须：①气液处理量大而不发生雾沫夹带/液泛；②操作稳定、弹性大；③流体阻力（压降）小；④结构简单、耗材少；⑤耐腐蚀、易检修；⑥塔内滞留量小。

### 1.2 板式塔类型
筛板塔（结构简单、造价低、压降低、处理量适中）；浮阀塔（弹性大）。本设计选**筛板塔**。

### 1.3 精馏塔设计步骤
工艺计算 → 塔板结构设计 → 流体力学验算 → 附属设备选型 → 绘图。

---

## 第二章 设计方案的确定

- **操作压力**：常压（101.3 kPa）。
- **进料状态**：饱和液体进料（泡点，q=1）。
- **加热方式**：**直接蒸汽加热**（塔底设盘管式蒸汽鼓泡器，省去再沸器；釜液几乎全是水）。
- **冷却剂**：水，进口 30℃、出口 45℃。
- **流程**：原料经预热至泡点→精馏塔→塔顶蒸汽入全凝器→回流罐→部分回流、部分采出；塔底直接通蒸汽、釜液排出。

## 第三章 精馏塔的工艺计算

### 3.1 物料衡算

**3.1.1 摩尔分率**（乙醇 M_A=46，水 M_B=18）

- 进料 aF=38.93% → `xF = (0.3893/46)/(0.3893/46 + 0.6107/18) = 0.1996`
- 塔顶 aD=93.52% → `xD = (0.9352/46)/(0.9352/46 + 0.0648/18) = 0.8496`
- 塔釜 aW=0.3% → `xW = (0.003/46)/(0.003/46 + 0.997/18) = 0.00118`

**3.1.2 平均摩尔质量**

- MF = 46×0.1996 + 18×0.8004 = **23.59 kg/kmol**
- MD = 46×0.8496 + 18×0.1504 = **41.79 kg/kmol**
- MW = 46×0.00118 + 18×0.99882 = **18.03 kg/kmol**

**3.1.3 进料热状况**：泡点进料，插值得 tF≈83.3℃，q=1。

**3.1.4 最小回流比（切线法）**

从 (xD,xD)=(0.8496,0.8496) 作平衡线切线，切点 (0.741, 0.780)，切线 y 轴截距 ym=0.3027：

```
Rmin = xD/ym − 1 = 0.8496/0.3027 − 1 = 1.81
R = 1.41 × Rmin = 1.41 × 1.81 = 2.55
```

**3.1.5 直接加热物料衡算**

- 塔顶产品：`D = 24000/24/MD = 1000/41.79 = 23.93 kmol/h`
- 加热蒸汽：`S = (R+1)D = (2.55+1)×23.93 = 84.90 kmol/h`
- 原料量：`F = [D(xD−xW) + S·xW]/(xF−xW) = 102.30 kmol/h`
- 釜液量：`W = F − D + S = 102.30 − 23.93 + 84.90 = 163.26 kmol/h`
- 釜液组成核算：`xW* = (F·xF − D·xD)/W = (102.30×0.1996 − 23.93×0.8496)/163.26 = 0.00056`

### 3.2 理论塔板数（图解法）

- 精馏段操作线：`y = R/(R+1)·x + xD/(R+1) = 0.7182x + 0.2395`
- q 线：x = xF = 0.1996（竖直线）
- 提馏段操作线：过 (xW*, 0) = (0.00056, 0)，斜率 L'/S = 163.26/84.90 = 1.92
- 从 (xD,xD) 起步进阶梯，画到 x≤xW*：**理论级数 27（含塔釜），理论板 N = 26**（精馏段 23、提馏段 3）

### 3.3 操作条件及物性估算

- **操作温度**：塔顶 t1=78.2℃、进料 tF=83.3℃、塔釜 tW=99.5℃；精馏段平均 80.8℃、提馏段平均 91.4℃、全塔平均 88.9℃
- **平均摩尔质量**：精馏段液相 ML=41.5、气相 MV=41.8；提馏段液相 ML=18.0、气相 MV≈32.9 kg/kmol
- **液相平均粘度**：`μ混^(1/3) = Σ xi·μi^(1/3)`（乙醇/水粘度查手册插值），全塔 μL≈0.33 mPa·s
- **相对挥发度**：逐板 `αi = yi(1−xi)/[xi(1−yi)]`，几何平均 αm≈1.9
- **总板效率**：`ET = 1.1×0.49(αm·μL)^(−0.245) = 0.60`
- **实际板数**：精馏段 23/0.60≈38 块、提馏段 3/0.60≈6 块，**总实际板 Ne = 44**（加料板在第 39 块附近）
- **操作压力**：每板压降约 0.7 kPa，塔釜表压约 18到20 kPa

### 3.4 气液相负荷

- 精馏段：`L = RD = 2.55×23.93 = 61.0 kmol/h`；`V = (R+1)D = 84.90 kmol/h`
- 提馏段：`L' = L + F = 61.0 + 102.30 = 163.3 kmol/h`；`V' = S = 84.90 kmol/h`

### 3.5 工艺尺寸

- 泛点气速 `uF = C·√((ρL−ρG)/ρG)`，C = C20·(σ/20)^0.2（C20 查 Smith 图）
- 空塔气速 `u = 0.8uF`；有效面积 `An = V/u`；总截面积 `A = An/(1−Ad/A)`；`D = √(4A/π)`
- 结果：**精馏段 D = 0.90 → 1.0 m**；提馏段 D = 0.72 → 0.8 m（统一用精馏段 1.0 m）
- 塔有效高度 `HE = (38−1)×0.35 + (6−1)×0.65 ≈ 16.2 m`

### 3.6 塔板设计

- 溢流装置：堰长 `lw = 0.7D = 700 mm`；堰上液头 `how = 0.0028Fw(L/lw)^(2/3)`（Fw=1.02）；板上清液层 `hL = hw + how = 50 mm` → 堰高 hw≈40 mm；降液管底隙 hH=30 mm
- 筛板：孔径 d0=5 mm、孔距 t=14 mm（正三角形）、开孔率 `φ = 0.907(d0/t)² = 0.116`；鼓泡区 Aa；开孔区 `A0 = φ·Aa`；孔数 `n = 1.155·Aa/t²`；孔速 `u0 = V/A0`

### 3.7 流体力学验算

- 单板压降 `ΔHt = h0 + he`，`h0 = (1/2g)(u0/C0)²(ρV/ρL)`（C0=0.82）、`he = β(hw+how)`（β=0.6）；全塔压降 `N·ΔHt·ρL·g ≤ 30 kPa`
- 降液管液面 `Hd = hL + hd + ΔHt ≤ φ(HT+hw)`（φ=0.6）
- 停留时间 `τ = Hd·Ad/VL > 3 s`
- 雾沫夹带（Hunt）`eV = (0.0057/σ)·[u/(HT−2.5hL)]^3.2 < 0.1`
- 漏液 `u0,min = C0√(2g·h0,min·ρL/ρV)`，稳定系数 `u0/u0,min > 1.5`

### 3.8 塔板负荷性能图

五条线（漏液线、液泛线、雾沫夹带上限线、液相流率下限线、液相流率上限线）+ 操作点 + 操作线；操作弹性 2到3、稳定系数 >1.5。

## 第四章 结果与结论

本设计对日产 24 吨 93.52% 乙醇的乙醇-水筛板精馏塔完成了物料衡算、回流比、理论/实际板数、塔径、塔板结构、流体力学验算与附属设备选型。主要结果：理论板 26 块、实际板 44 块、塔径 1.0 m、全塔高约 20 m，各项校验（液泛、雾沫夹带、漏液、停留时间）均满足要求。

## 第五章 塔附件计算

- **接管**（五种，`d = √(4V/(πu))` 圆整到标准管）：进料管、回流管、塔底出料管、塔顶蒸汽出料管、塔底进气管
- **筒体封头**：筒体 DN1000×6、椭圆封头 DN1000×6
- **裙座**：Ø1000×6，高 1.5 m
- **吊柱、人孔**：人孔 Φ600，每隔 6到8 块塔板设一个
- **塔总体高度**：塔顶空间 1.0 m + 塔板段 16.2 m + 塔底空间 1.0 m + 裙座 1.5 m ≈ 20 m
- **附属设备**：
  - 全凝器：塔顶蒸汽潜热 r≈948.9 kJ/kg，热负荷 `QT = D(R+1)·r ≈ 935 kW`；冷却水量 14.91 kg/s（30→45℃）；换热面积 `A = QT/(K·Δtm) ≈ 25.4 m²`（K=915）
  - 原料预热器、进料泵、回流泵（按负荷与扬程选型）
