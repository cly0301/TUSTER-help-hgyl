## 第一章 概述

### 1.1 精馏操作对塔设备的要求
精馏是气液两相传质过程，塔设备须使气液两相充分接触以达到较高的传质效率，并满足：①气液处理量大而不发生雾沫夹带/拦液/液泛；②操作稳定、弹性大；③流体阻力（压降）小；④结构简单、材料耗用量小、制造安装容易；⑤耐腐蚀、易堵塞、方便操作检修；⑥塔内滞留量小。实际上，任何塔设备都难以满足上述所有要求，且有些要求互相矛盾，不同塔型各有独特优点，设计时应按物系性质抓住主要矛盾进行选型。

### 1.2 板式塔类型
气液传质设备分板式塔和填料塔，本设计只讨论板式塔。板式塔按气液接触元件分泡罩塔、浮阀塔、筛板塔等，目前主要塔型为浮阀塔与筛板塔。
- **筛板塔**：优点：结构简单、造价约为泡罩塔60%/浮阀塔80%、处理能力大（比泡罩塔高10到15%）、塔板效率高（比泡罩塔高15%）、压降低（每板比泡罩塔低30%）。缺点：安装水平度要求高、操作弹性较小（约2到3）、小孔易堵。
- **浮阀塔**：优点：浮阀随气量上下浮动自动调节、处理能力大、操作弹性大（5到9）、塔板效率高、压降小。缺点：结构比筛板复杂、造价为筛板塔的120到130%。
**本次设计选用筛板塔**（结构简单、造价低、压降低；乙醇-水对操作弹性要求不高）。

### 1.3 精馏塔设计步骤
①设计方案确定和说明；②蒸馏塔工艺计算；③塔板设计（工艺尺寸、流体力学验算）；④管路及附属设备计算选型；⑤抄写说明书；⑥绘制工艺流程图和精馏塔设备图。

## 第二章 设计方案的确定

### 2.1 操作条件的确定
- **操作压力**：物性无特殊要求时一般在稍高于大气压下操作，本设计取**常压（101.3 kPa）**。
- **进料状态**：料液预热到泡点送入塔中，本设计取**泡点进料（q=1）**。
- **加热方式**：蒸馏釜通常用间接蒸汽加热（设再沸器）；当塔底产物近于纯水、浓度稀薄时相对挥发度大（如酒精-水），可用**直接蒸汽加热**：优点：可用较低压力蒸汽、釜内只装鼓泡管不设庞大传热面、省操作费和设备费；缺点：蒸汽稀释使塔板数稍增，但稀薄时增加不多，故合适。本设计取**直接蒸汽加热**。
- **冷却剂与出口温度**：塔顶蒸汽温度低，用常温水冷却；出口温度不超过 50℃。本设计冷却水 30→45℃。
- **热能的利用**：精馏是反复汽化冷凝的耗能过程；选取适宜回流比使能耗最低；可用釜液预热原料、塔顶蒸汽冷凝潜热加热低能级物料。

### 2.2 精馏流程示意图
连续精馏。乙醇-水溶液经卧式列管换热器预热后送入精馏塔；塔顶上升蒸汽经列管式全凝器冷凝后入回流罐，部分回流、其余作塔顶产品；塔釜直接蒸汽供热，塔底产品排出。

### 2.3 确定设计方案的原则
总原则是在可能条件下尽量采用先进技术，使生产技术上最先进、经济上最合理，符合优质、高产、安全、低消耗。
- ①满足工艺和操作要求（质量稳定、操作弹性、仪表控制）；
- ②满足经济要求（省热省电、减少设备费）；
- ③保证安全生产（易燃物料不泄漏、常压塔设安全装置）。
课设中对①多考虑、②定性考虑、③一般考虑。

## 第三章 精馏塔的工艺计算

### 3.1 物料衡算

**3.1.1 摩尔分率**（乙醇 M_A=46，水 M_B=18）

- 进料：`xF = (0.3957/46)/(0.3957/46 + 0.6043/18) = 0.2040`
- 塔顶：`xD = (0.9404/46)/(0.9404/46 + 0.0596/18) = 0.8606`
- 塔釜：`xW = (0.003/46)/(0.003/46 + 0.997/18) = 0.00118`

**3.1.2 平均摩尔质量**

- MF = 46×0.2040 + 18×0.7960 = **23.71 kg/kmol**
- MD = 46×0.8606 + 18×0.1394 = **42.10 kg/kmol**
- MW = 46×0.00118 + 18×0.99882 = **18.03 kg/kmol**

**3.1.3 进料热状况**：泡点进料，插值得 tF≈83.2℃，q=1。

**3.1.4 最小回流比（切线法）**

从 (xD,xD)=(0.8606,0.8606) 作平衡线切线，切点 (0.781, 0.806)，切线 y 轴截距 ym=0.2669：

```
Rmin = xD/ym − 1 = 0.8606/0.2669 − 1 = 2.22
R = 1.67 × Rmin = 1.67 × 2.22 = 3.72
```

**3.1.5 直接加热物料衡算**

- 塔顶产品：`D = 24000/24/MD = 1000/42.10 = 23.75 kmol/h`
- 加热蒸汽：`S = (R+1)D = (3.72+1)×23.75 = 112.01 kmol/h`
- 原料量：`F = [D(xD−xW) + S·xW]/(xF−xW) = 100.67 kmol/h`
- 釜液量：`W = F − D + S = 100.67 − 23.75 + 112.01 = 188.93 kmol/h`
- 釜液组成核算：`xW* = (F·xF − D·xD)/W = (100.67×0.2040 − 23.75×0.8606)/188.93 = 0.00048`

### 3.2 理论塔板数（图解法）

- 精馏段操作线：`y = R/(R+1)·x + xD/(R+1) = 0.7880x + 0.1825`
- q 线：x = xF = 0.2040；提馏段操作线过 (xW*, 0)
- 从 (xD,xD) 起步进阶梯，画到 x≤xW*：**理论级数 25（含塔釜），理论板 N = 24**（精馏段 21、提馏段 3）

### 3.3 操作条件及物性估算

- **操作温度**：塔顶 t1=78.20℃、进料 tF=83.2℃、塔釜 tW=99.51℃
- **液相平均粘度**：`μ混^(1/3) = Σ xi·μi^(1/3)`，全塔 μL≈0.330 mPa·s
- **相对挥发度**：逐板取几何平均 αm≈1.96
- **总板效率**：`ET = 1.1×0.49(αm·μL)^(−0.245) = 0.60`
- **实际板数**：精馏段 21/0.60≈34 块、提馏段 3/0.60≈7 块，**总实际板 Ne = 41**（加料板在第 35 块附近）
- **操作压力**：每板压降约 0.7 kPa，塔釜表压约 18到20 kPa

### 3.4 气液相负荷

- 精馏段：`L = RD = 3.72×23.75 = 88.3 kmol/h`；`V = (R+1)D = 112.01 kmol/h`
- 提馏段：`L' = L + F = 88.3 + 100.67 = 188.9 kmol/h`；`V' = S = 112.01 kmol/h`

### 3.5 工艺尺寸

- 泛点气速 `uF = C√((ρL−ρG)/ρG)`，C = C20(σ/20)^0.2（C20 查 Smith 图）
- 空塔气速 `u = 0.8uF`；`An = V/u`；`A = An/(1−Ad/A)`；`D = √(4A/π)`
- 结果：**精馏段 D = 1.05 → 1.1 m**；提馏段 D = 0.82 → 0.9 m（统一用精馏段 1.1 m）

### 3.6 塔板设计

- **溢流装置**：堰长 `lw = 0.7D = 770 mm`；堰上液头 `how = 0.0028×1.02×(4.92/0.77)^(2/3) = 9.8 mm`（>6 mm ✓）；hL=50 mm → 堰高 `hw = 50 − 9.8 = 40.2 mm`；降液管底隙 hH=30 mm
- **降液管**：宽 `Wd = R − √(R²−(lw/2)²) = 157 mm`；面积 `Ad = 0.083 m²`（Ad/A≈0.088）
- **筛板**：d0=5 mm、t=14 mm、开孔率 `φ = 0.116`；鼓泡区 `Aa = 0.61 m²`；开孔区 `A0 = 0.071 m²`；孔数 `n ≈ 3613`；孔速 `u0 ≈ 12.6 m/s`；板厚 tp=4 mm

### 3.7 流体力学验算

- 单板压降 `ΔHt = h0 + he`；全塔压降 ≤30 kPa
- 降液管液面 `Hd = hL + hd + ΔHt ≤ φ(HT+hw)`（φ=0.6）
- 停留时间 `τ = Hd·Ad/VL > 3 s`
- 雾沫夹带（Hunt）`eV < 0.1`；漏液 `u0,min = C0√(2g·h0,min·ρL/ρV)`，稳定系数 >1.5

### 3.8 塔板负荷性能图

五条线 + 操作点 + 操作线；操作弹性 2到3、稳定系数 >1.5。

## 第四章 结果与结论

### 4.1 设计计算结果
本设计对日产 24 吨 94.04% 乙醇的乙醇-水筛板精馏塔完成了物料衡算、回流比、理论/实际板数、塔径、塔板结构、流体力学验算与附属设备选型，各项校核均满足要求。

### 4.2 设计工艺参数及设计条件
操作压力常压、泡点进料、直接蒸汽加热；理论板 24 块、实际板 41 块、塔径 1.1 m、全塔高约 23.6 m。

## 第五章 塔附件计算

- **接管**（五种）：进料管、回流管、塔底出料管、塔顶蒸汽出料管、塔底进气管（液速 0.3到0.5、气速 15 m/s）
- **筒体封头**：筒体 DN1100×6、椭圆封头 DN1100×6
- **裙座**：Ø1100×6，高 1.5 m；**人孔**：Φ600，每 6 块塔板一个（共 6 个）
- **塔总体高度**：塔板段 16,500 + 人孔加高 3,600 + 塔顶 1,000 + 塔底 1,000 + 裙座 1,500 = **23,600 mm ≈ 23.6 m**
- **全凝器**：塔顶蒸汽潜热 r≈941.4 kJ/kg，热负荷 `QT = D(R+1)·r ≈ 1233 kW`；冷却水量 19.67 kg/s（30→45℃）；换热面积 `A = QT/(K·Δtm) ≈ 33.5 m²`（K=915）
- **原料预热器、进料泵、回流泵**：按负荷与扬程选型
