## 2. （一）物料衡算

### 2.1 组成与单位换算

1. 原料液组成用 `x_F` 表示（质量分数 w_F 换算为摩尔分数）
2. 塔顶产品组成用 `x_D` 表示（质量分数 w_D 换算为摩尔分数）
3. 塔底残液组成用 `x_W` 表示（质量分数 w_W = 0.3%，换算为摩尔分数，全体统一）

质量分数→摩尔分数换算（M_A、M_B 为两组分摩尔质量，M_A 为乙醇 46）：

```
x_F = (w_F / M_A) / [ w_F/M_A + (1-w_F)/M_B ]      (3-1)
x_D = (w_D / M_A) / [ w_D/M_A + (1-w_D)/M_B ]      (3-1a)
x_W = (w_W / M_A) / [ w_W/M_A + (1-w_W)/M_B ]      (3-1b)
```

混合物平均摩尔质量：

```
M_i = M_A·x_i + M_B·(1-x_i)                        (3-2)
```

### 2.2 全塔物料衡算

**间接蒸汽加热：**

```
F = D + W
F·x_F = D·x_D + W·x_W
```

**直接蒸汽加热（酒精精馏塔常采用）：**

```
F + S = D + W          （S 为直接加热蒸汽用量）
F·x_F = D·x_D + W·x_W
S = V = V' = (R+1)·D   （直接蒸汽用量，见回流比确定后回到衡算确定 S）
```

> 确定回流比 R 后，要回到物料衡算中再确定直接蒸汽用量 S 等。

## 3. （二）回流比 R（图解法）

### 3.1 作出 x–y 相图

- 平衡数据见教材附录（乙醇-水为非理想体系）。

### 3.2 确定最小回流比 R_min

- 正常（理想）平衡线：由 a 点（xD, xD）作操作线交平衡线于夹点。
- **非理想物系（乙醇-水）**：平衡线有下凹，最小回流比由**从 (xD, xD) 点作平衡线的切线**（切点 e）确定；切线在 y 轴上的截距 = `x_D / (R_min + 1)`。

### 3.3 定回流比 R

```
R = (1.1 ~ 2)·R_min          （一般经验范围）
R = (1.4 + 学号后两位×0.01)·R_min   （本设计规定）
```

精馏段操作线（定点截距法：过点 (xD, xD)，y 轴截距 xD/(R+1)）：

```
y = (R/(R+1))·x + x_D/(R+1)
```

## 4. （三）理论板数 N、塔板效率 E、实际板数 Ne

### 4.1 理论板数的求法

- 简捷法（近似）
- 逐板计算法（近似）
- **图解法（本设计采用 McCabe-Thiele 图解，即 M-T 图解）**

**图解要点（直接蒸汽加热流程）：**
- 精馏段操作线：定点截距法（过 (xD, xD)，截距 xD/(R+1)）。
- 提馏段操作线：过 (x_W, x_W)（间接蒸汽）或过 **点 (x_W*, 0)**（直接蒸汽，见下）。
- 进料线（q 线）。
- **直接蒸汽加热时，梯级作到 x_W* 处，读出一位小数。**

**图解理论板要求：**
- 标注图的题目；标注塔板号（梯级数）。
- 塔顶、塔釜局部放大；放大倍数选择适当；放大图与原图要对应一致。
- 平衡曲线用曲线板连接，曲线光滑流畅，线条粗细适当。
- 要有图解痕迹：平衡线、精馏段/提馏段操作线、求最小回流比的切线、进料线、对角线等均须标注；各关键点标注（塔顶、塔釜、进料组成、切点坐标、y 轴截距、两操作线交点、提馏段操作线与 x 轴交点等）。

> 理论板数 N = 梯级数 − 1。

### 4.2 全塔板效率 E（O'Connell 关联图）

- **查图**：O'Connell 关联图（教材 P145 图 11-21），横坐标为 `α·μ_L`。
- 横坐标 `α·μ_L` 的确定：
  - `α`：对非理想溶液可取**各板相对挥发度的几何平均**：
    ```
    α_i = y_i(1-x_i) / [ x_i(1-y_i) ]
    α = (α_1·α_2·…·α_N)^(1/N)
    ```
  - `μ_L`：以进料 x_F 为基准的液体平均黏度（两组分在全塔平均温度下黏度加和）：
    ```
    μ_L = μ_A·x_F + μ_B·(1-x_F)
    ```
  - 平均塔温 = 塔顶温度与塔釜温度的平均值。
- **修正**：O'Connell 关联图/关联式是**泡罩塔**的，对**筛板塔要乘修正系数 1.1**（即 E_筛板 = 1.1 × E_泡罩）。
- ★补注：O'Connell 关联式 `E = 0.49(α·μ_L)^(-0.245)`。

### 4.3 实际板数 Ne

```
实际板数 Ne = 理论板数 N / 塔板效率 E
```

- **实际板数取整！**
- 精馏段：`Ne精 = N_T精 / E`
- 提馏段：`Ne提 = N_T提 / E`（课件原文写法 `Ne提 = N_T提 - Ne1`，意为提馏段实际板数另行分段计算）
- 说明加料板位置。
- **实际板数为两段分别取整后的和！**

## 5. （四）塔径计算

### 5.1 基本思路

- 由塔内适宜气速计算塔径；塔内上升蒸汽的体积流量与塔截面积决定塔径。
- 板式塔直径 `D`：

```
u = V / A           （u：空塔气速，V：体积流量）
D = √(4A/π)
```

### 5.2 液泛气速（最大空塔气速 u_max）

- 两种液泛现象：**夹带液泛**、**溢流液泛**。
- 不正常操作：夹带液泛、溢流液泛、严重漏液。

**泛点气速关联式（Fair, 1961）：**

```
u_F = C·√[ (ρ_L − ρ_V) / ρ_V ]
```

- `C`：气体负荷参数（气体负荷因子）。
- `ρ_V`：气相混合物平均密度；`ρ_L`：液相混合物平均密度。

### 5.3 气体负荷参数 C 的确定

**（1）C20（图 3-13 板式塔气体负荷系数 C20 关联图）：**
- C20 由**液气流动参数 FP（= F_LV）与板间距 H_T** 查图确定。
- 计算塔径前须先选一个板距 H_T（300 mm、400 mm、450 mm 等，见相关资料）。
- 流动参数：
  ```
  F_LV = (V_L / V_V)·√(ρ_L / ρ_V)
  ```
  - 精馏段以**塔顶第一块板**为准；
  - 提馏段以**加料板（或其下一块板）**为准。

**（2）C 的修正：**

```
C = C20·(σ/20)^0.2
```

- 仅当液体表面张力 σ = 20 mN/m（0.02 N/m）时 C = C20；σ ≠ 20 mN/m 需修正。

**（3）表面张力 σ 的计算（基团贡献法 / 等张比容法）：**

```
σ = [ Pm·(ρ_L − ρ_V)×10⁻³ / Mm_L ]^0.5    （★课件公式）
```

- `Pm`：平均分子常数（等张比容 parachor），`Pm = P_A·x_i + P_B·(1-x_i)`。
- 各物质分子常数 P_i 由原子/基团常数加和求得（查表 3-6 常见物质分子常数一览表）。

**表 3-6 常见物质（原子/基团）分子常数（等张比容）一览（摘录）：**

| 原子/基团 | 分子常数 | 原子/基团 | 分子常数 |
|---|---|---|---|
| C | 4.8 | H（与 O 相连） | 11.3 |
| H（与 C 相连） | 17.1 | O（酸中，包括羟基） | 20.0 |
| O（碳水化合物中） | 43.2 | O（酯、醚中） | 60.0 |
| N（胺中） | 12.5 | N | 29.1 |
| S | 48.2 | F | 25.7 |
| Cl | 54.3 | Br | 68.0 |
| I | 91.0 | 双键 | 23.2 |
| 三键 | 46.6 | 三环 | 16.7 |
| 四环 | 11.6 | 五环 | 8.5 |
| 六环 | 6.1 | | |

### 5.4 塔径的计算

- 实际气速：

```
u = (0.5 ~ 0.8)·u_F
```

- 系数按实际情况选取：一般液体 0.7~0.8；发泡液体 0.5~0.6。
- 塔有效截面积：`A_n = V / u`
- 塔总截面积：`A = A_n / (1 − A_d/A)`（A_d/A：降液管截面积与塔截面积之比，查表/图确定，见表 3-14 弓形降液管尺寸参数）
- 塔径：`D = √(4A/π)`，**按要求圆整**。

**塔径计算流程小结（参考教材第 11 章例 11-1）：**
```
气相 V_V、ρ_V  ┐
液相 V_L、ρ_L  ┘ → 查图得 C20 → C = C20(σ/20)^0.2
→ u_F = C√[(ρ_L−ρ_V)/ρ_V] → 算 u → 算 A_n = V_V/u
→ A = A_n/(1−A_d/A) → D = √(4A/π)
```

### 5.5 塔径的校核（液泛分率）

```
圆整后：A = (π/4)·D²，A_n = A·(1 − A_d/A)，u = V/V_n
校核：u / u_F < 0.9
```

- 若液泛分率超过 0.9，重新计算塔径，反复校核直到满足要求。

### 5.6 塔径圆整规则与提馏段塔径

- 塔径 ≤ 1000 mm：以 100 mm 递增圆整；
- 塔径 > 1000 mm：以 200 mm 递增圆整。
- 按圆整后的塔径重新计算塔截面积 A。
- 精馏段塔径以塔顶第一块板为准，提馏段以加料板（或加料板下一块板）为准。
- 若两段塔径不同，**不设计异径塔，用精馏段统一塔径**（但提馏段塔径也需要计算）。

## 6. （五）塔高计算

推荐公式（《化工手册》介绍）：

```
H = H_D + (N − 2 − S)·H_T + S·H_T' + H_F + H_B
```

符号含义与取值范围：

- `H`：塔高（**不包括封头、裙座**），m
- `N`：实际塔板数
- `S`：人孔或手孔数目，**每隔 6~8 块设一人孔或手孔**
- `H_T`：塔板间距
- `H_T'`：开有人孔或手孔的板间距；手孔 Φ150 mm，人孔 Φ600 mm，`H_T' = H_T + Φ`
- `H_D`：塔顶空间（不包括头盖部分），取 **1~1.2 m**
- `H_B`：塔底空间（不包括底盖部分），取 **1 m 左右**
- `H_F`：进料板处的板间距（进料板一般可兼设人孔、手孔）

人孔/手孔设置：
- `D ≤ 800 mm`：设手孔（人孔可兼作手孔）
- `D ≥ 900 mm`：设人孔（加料板可兼设人孔或手孔）
- 若物系不含固体杂质、发泡性不强，人孔/手孔间距可适当加大。

## 7. （六）塔板、降液管的结构设计

### 7.1 设计思路

选择塔板/降液管各结构尺寸 → 流体力学（水力）校核（如是否漏液）→ 不满意则调整尺寸重新选 → 满意即结束。

### 7.2 溢流堰及降液管尺寸（经验范围选定）

- 塔板直径 `D`：同塔径
- 堰长 `l_w`：单流型塔板 `l_w/D = 0.6~0.8`；双流型塔板 `l_w/D = 0.5~0.7`
- 降液管截面积 `A_d`、弓形降液管宽度 `W_d`：由 `l_w/D` 查表/图（表 3-14 弓形降液管尺寸参数）确定。

### 7.3 降液管底隙高 h_H

```
20 mm < h_H < h_w − (5~10) mm
```

- 注意：要保证液体顺利流出，并**形成液封**（底隙低于堰高，堰高在降液管底端 6 mm 以上）。

### 7.4 堰上液层高度 h_ow（按塔顶条件设计）

Francis 公式：

```
h_ow = 0.0028·F_w·(V_L / l_w)^(2/3)        （单位 m，V_L 液体体积流量 m³/h）
```

- 为避免试算可取 `F_w = 1`。
- 要求 `h_ow > 6 mm`，才能保证液体溢流沿堰均匀。

### 7.5 板上液层高度 h_L

```
h_L = h_w + h_ow        （板上清液层高度）
```

### 7.6 塔板布置（本次设计推荐参数）

- 安定区宽度 `W_s`：50~100 mm（根据情况选定）
- 孔区到塔壁距离（边缘区宽度）`W_c`：25~75 mm
- 孔径 `d0`：`d0 = 3~8 mm`
- 孔距 `t`：`t = (2.5~5)·d0`（t/d0 太小易汽流相互扰动，太大鼓泡不均匀、影响传质效率）
- 板厚 `t_p`：`t_p = 3~4 mm`；不锈钢 `t_p = 2~2.5 mm`

**开孔率的确定（正三角形排列，本设计推荐）：**

```
开孔率 φ = 筛孔总面积 / 开孔区面积
φ = (3·πd0²/4) / (1/2·t·t·sin60°) = 0.907·(d0/t)²
```

- 开孔率大 → 塔板压降低、雾沫夹带量小，但操作弹性小、漏液量大、塔板效率低。

**筛孔气速：**

```
u0 = V_V / A0        （V_V 气相体积流量，A0 开孔区面积）
```

**孔数的确定：**

```
n = A0 / [ (π/4)·d0² ]        （提馏段筛板孔数及排布为选做）
```

### 7.7 塔板结构参数计算结果表（说明书内应汇总）

塔径 D、塔截面积 A、板间距 H_T、堰长 l_w、降液管宽度 W_d、边缘区宽度 W_c、安定区宽度 W_s、出口堰上液层高度 h_ow、出口堰宽（高）h_w、降液管底隙高 h_H、降液管截面积 A_d、鼓泡区面积 A_a、开孔区面积 A0、孔间距 t、孔径 d0、精馏段开孔率 φ、精馏段孔数 n、孔速 u0 等。

## 8. （七）流体力学验算（水力学校核）

### 校核项目清单

1. 精馏段最后一块塔板堰上液层高度 h_ow（已在结构设计完成）
2. 全塔压降
3. 降液管内液面高度 H_d
4. 液体在降液管内停留时间
5. 液沫夹带量（雾沫夹带量）e_v
6. 漏液

> 先定性判断各结构尺寸对上述校核结果的影响。

### 8.1 堰上液头 h_ow 校核

```
h_ow = 0.0028·F_w·(L/l_w)^(2/3) > 6 mm      （取 F_w = 1）
```

不合格（<6 mm）怎么办：调整堰长 l_w 等尺寸。

### 8.2 全塔压降 / 单板压降校核

```
全塔压降 = 总板数 × 单板压降
```

单板压降 = 干板压降 + 液层压降（两个串联阻力）：

```
ΔH_t = h0 + he
```

- `h0`：干板压降（气体通过筛孔，借用流体通过孔板公式——突然缩小与突然扩大）：

```
h0 = (1/2g)·(u0/C0)²·(ρ_V/ρ_L)
```

- `he`：液层压降（板上液层有效阻力）：

```
he = β·(h_w + h_ow)       （修正系数 β 查图 3-22）
```

- 压降影响：板上液体操作；决定沿塔高的压力分布与温度分布。
- 工业上酒精精馏塔塔釜表压一般为 **18~20 kPa**；设计要求塔釜表压**不高于 30 kPa**。

### 8.3 降液管内液面高度 H_d 校核

```
H_d = h_L + Δ + ΔH_t + h_d
```

- `h_d`：液体通过降液管的压降
- `ΔH_t`：单板总压力降（已完成）
- `h_L`：板上清液层高度（已完成）
- `Δ`：液面落差——液体横向流过塔板克服摩擦阻力与构件局部阻力所需的液位差（推动力）。**筛板塔气体从筛孔穿过阻力小，液面落差 Δ 一般可忽略。**

校核要求（泡沫层总高度不得超过降液管高度，否则液泛）：

```
H_d / φ < H_T + h_w
```

> ★补注：φ 为泡沫密度系数（一般 0.3~0.6），即 `H_d ≤ φ(H_T + h_w)`。

### 8.4 液体在降液管内停留时间 τ 校核

```
τ = H_d·A_d / V_L
```

校核要求：`τ > 3 s`（否则过多气泡来不及从降液管液体中解脱出来而带入下层塔板）。

### 8.5 液沫夹带校核

- 定义：下层板的液体被气体带到上层板与之混合；板式塔即使低于液泛气速操作，气体中仍带液沫，导致板效率下降，筛板塔操作上限受其限制。
- 两种表示方法与要求：
  - **法一**：每摩尔干气所夹带液沫的摩尔数 `e_v < 0.1`
  - **法二**：液沫夹带分数 `Ψ = e/(L+e)`，`Ψ < 0.15`
  - 两者关系：`Ψ = e_v / (L/V + e_v)`

**法一 常用计算模型（Hunt 公式）：**

```
e_v = (0.0057/σ)·[ u / (H_T − 2.5(h_w + h_ow)) ]^3.2      < 0.1
```

- `u`：液层上部操作气速，`u = V_V / (A_D − A_d)`，`A_n = A_D − A_d` 为有效面积。
- `σ`：表面张力（mN/m）。
- 影响液沫夹带最主要的因素为气速 u 与板间距。若 `e_v > 0.1` 不合格，应适当加大塔径或加大板间距。

**法二 液沫夹带分数 ψ：**
- 计算液泛分率 `u实际/u_F`；
- 计算 `F_LV = (V_L/V_V)·√(ρ_L/ρ_V)`（以第一块板为准）；
- 查图 3-23（液沫夹带分率关联图），校核 `ψ < 0.15`。

### 8.6 漏液校核（筛板的下限气速 u_0,min）

漏液时的干板压降（简单计算模型）：

```
h_0,min = 0.0056 + 0.13(h_w + h_ow) − h_σ
h_σ = 4×10⁻³·σ / (ρ_L·g·d0)
```

漏液时的气体孔速 u_0,min：

```
h_0,min = (1/2g)·(u_0,min/C0)²·(ρ_V/ρ_L)
即  u_0,min = C0·√(2g·h_0,min·ρ_L/ρ_V)
```

校核要求：`u / u_0,min > 1.5`（稳定系数）。

### 8.7 计算结果小结（说明书内汇总）

- **主要尺寸**：板型、塔径 D、板距 H_T、降液管截面积 A_d、降液管底隙、堰长 l_w、堰高 h_w、孔径 d0、板厚 t_p、孔总面积 A0。
- **水力学性能**：液泛分率、液沫夹带分率、单板压降 ΔH_t、降液管内液体停留时间、堰上液头高度、降液管内液面高度 H_d。
- **几个气速值**：液泛气速 u_F、漏液点气速 u_0,min、实际气速 u、筛孔气速 u_0。

## 9. （八）负荷性能图 —— 适宜的汽、液流量范围

- 教材 P86 图 3-24。
- 物理含义：
  - 气量过小 → 漏液
  - 气量过大 → 液沫夹带
  - 液量过小 → 液面分布不均匀
  - 液量过大 → 液面落差大、甚至液泛

### 9.1 五条线及画法（手算时各线均视为直线，取两个 (V_L, V_V) 点即可作图）

1. **漏液线（气相负荷下限）**：
   ```
   h_ow = 0.0028F_w(L/l_w)^(2/3) > 6 mm
   V_V,min = 3600·u_0,min·A0
   ```
   取 V_L' = 2 个已知值，计算 V_V，按 V_V~V_L 关系取两点作漏液线。

2. **过量雾沫夹带线（气相负荷上限）**：令 `e_v = 0.1`（Hunt 公式），取 V_L' = 2 个已知值算 V_V，取两点作图。

3. **液相负荷下限线**：`h_ow = 6 mm` 作为下限，`h_ow = 0.0028F_w(V_L/l_w)^(2/3)`，推荐 F_w = 1.02，由算出的 V_L' 作垂线。

4. **液相负荷上限线**：液体在降液管内停留时间过短，气泡来不及分离带至下层塔板，`τ = H_d·A_d/V_L > 3 s`，按 `τ_min = H_d·A_d/V_L,max = 3 s` 计算，由算出的 V_L 作垂线。

5. **液泛线**：操作线若位于液泛线上方将引起液泛（条件 H_d = H_T + h_w）。本次设计不受液泛线控制，但也必须画出。

（课件对五条线用隐式函数标注：`F(V_L)=0.006 m` 液相负荷下限线、`G(V_L,V_V)=0.1` 液沫夹带上限线、`H(V_L,V_V)` 液泛线、`J(V_L)=3` 液相负荷上限线、`K(V_L,V_V)` 漏液线。）

### 9.2 操作点、操作弹性与稳定系数

- **操作点**：操作时塔顶气相流量与液相流量在负荷性能图上的点 (L_s, V_s)。
- **操作线**：原点与操作点 (L_s, V_s) 的连线。
- **操作弹性**：气相负荷上、下限之比 `V_s,max/V_s,min = 2~3`。
- **稳定系数**：操作气量与最小气量之比 `V_s/V_s,min > 1.5`。

### 14.1 绘图国家标准简介

### 14.2 图纸幅面与格式（GB/T 14689-2008）

| 幅面代号 | 尺寸/mm（长×宽） | 装订边 | 留装订边其余边 | 不留装订边边距 |

| A2 | 420×594 | 25 | 10 | 20 |
| A3 | 297×420 | 25 | 10 | 20 |

- 图框格式分「不留装订边」和「留装订边」两种，同一产品只能采用一种格式。
- 图纸长与宽的比例约为 **1.4 : 1**。

### 14.3 标题栏（GB/T 10609.1-2008 技术制图 标题栏）

- 每张图样必须画标题栏；格式和尺寸按 GB/T 10609.1-2008 规定。
- 标题栏位于图纸**右下角**；标题栏中的文字方向为看图方向。

### 14.4 铅笔选用

- 粗实线：2B 或 B
- 细实线、细虚线、细点划线：H 或 HB
- 底稿：2H
- H、HB、2H 削成**锥形**；2B、B 削成**矩形**。

### 14.5 绘图步骤

**（1）绘图准备**：定比例 → 选图纸 → 固定图纸 → 画图框 → 对齐符号与图例。
**（2）打底稿**：布局合理均匀，先画基准线与定位线；先画已知弧 → 再画中间弧 → 最后画连接弧；线条清晰准确、保持图面清洁。
**（3）加深加粗**（先检查草稿、改正错误、擦去错线、画辅助线）：
- ① 先粗后细：先加深全部粗实线，再加深细虚线、点划线、细实线；
- ② 先曲后直：同类型线（尤其粗实线）先画圆弧/圆，再画直线；
- ③ 先横后竖：用丁字尺自上而下画水平线，再用三角板从左到右画竖直线，最后画斜线；
- ④ 尺寸标注与标题栏填写（取下图纸后进行）。
- 要求同类线条粗细浓淡一致、光滑连续，文字图样工整。
