## 第一章 概述

### 1.1 精馏操作对塔设备的要求
精馏是气液两相传质过程，塔设备须：①气液处理量大而不发生雾沫夹带/液泛；②操作稳定、弹性大；③流体阻力（压降）小；④结构简单、耗材少；⑤耐腐蚀、易检修；⑥塔内滞留量小。

### 1.2 板式塔类型
筛板塔（结构简单、造价低、压降低、处理量适中）；浮阀塔（弹性大）。本设计选**筛板塔**。

### 1.3 精馏塔设计步骤
工艺计算 → 塔板结构设计 → 流体力学验算 → 附属设备选型 → 绘图。

---

## 第二章 设计方案的确定

- **操作压力**：常压（101.3 kPa）。
- **进料状态**：饱和液体进料（泡点，q=1）。
- **加热方式**：**直接蒸汽加热**（塔底设盘管式蒸汽鼓泡器，省去再沸器；釜液几乎全是水）。
- **冷却剂**：水，进口 30℃、出口 45℃。
- **流程**：原料经预热至泡点→精馏塔→塔顶蒸汽入全凝器→回流罐→部分回流、部分采出；塔底直接通蒸汽、釜液排出。

## 第三章 精馏塔的工艺计算

### 3.1 物料衡算

**3.1.1 摩尔分率**（乙醇 M_A=46，水 M_B=18）

- 进料 aF=38.93% → `xF = (0.3893/46)/(0.3893/46 + 0.6107/18) = 0.1996`
- 塔顶 aD=93.52% → `xD = (0.9352/46)/(0.9352/46 + 0.0648/18) = 0.8496`
- 塔釜 aW=0.3% → `xW = (0.003/46)/(0.003/46 + 0.997/18) = 0.00118`

**3.1.2 平均摩尔质量**

- MF = 46×0.1996 + 18×0.8004 = **23.59 kg/kmol**
- MD = 46×0.8496 + 18×0.1504 = **41.79 kg/kmol**
- MW = 46×0.00118 + 18×0.99882 = **18.03 kg/kmol**

**3.1.3 进料热状况**：泡点进料，插值得 tF≈83.3℃，q=1。

**3.1.4 最小回流比（切线法）**

乙醇-水平衡线有下凹，最小回流比由从 (xD,xD)=(0.8496,0.8496) 向平衡线作**切线**确定，切点 (0.741, 0.780)，该切线在 y 轴上的截距 ym=0.3027：

```
Rmin = xD/ym − 1 = 0.8496/0.3027 − 1 = 1.81
R = 1.41 × Rmin = 1.41 × 1.81 = 2.55
```

**3.1.5 直接加热物料衡算**

- 塔顶产品：`D = 1000/MD = 1000/41.79 = 23.93 kmol/h`
- 加热蒸汽：`S = (R+1)D = (2.55+1)×23.93 = 84.90 kmol/h`
- 原料量：`F = [D(xD−xW) + S·xW]/(xF−xW) = 102.80 kmol/h`
- 釜液量：`W = F − D + S = 102.80 − 23.93 + 84.90 = 163.77 kmol/h`
- 釜液组成核算：`xW* = (F·xF − D·xD)/W = (102.80×0.1996 − 23.93×0.8496)/163.77 = 0.00118`

> 核算得 `xW* = xW`，说明直接蒸汽加热的全塔衡算自洽。

### 3.2 理论塔板数（图解法）

- 精馏段操作线：`y = R/(R+1)·x + xD/(R+1) = 0.7182x + 0.2395`
- q 线：x = xF = 0.1996（竖直线）
- 提馏段操作线：过 (xW*, 0) = (0.00118, 0)，斜率 W/S = 163.77/84.90 = 1.93
- 从 (xD,xD) 起步进阶梯，画到 x≤xW*：**理论级数 26（含塔釜），理论板 N = 25**（精馏段 23、提馏段 3）

### 3.3 操作条件及物性估算

- **操作温度**：塔顶 t1=78.2℃、进料 tF=83.3℃、塔釜 tW=99.5℃；精馏段平均 80.8℃、提馏段平均 91.4℃、全塔平均 88.9℃
- **平均摩尔质量**：精馏段液相 ML=41.5、气相 MV=41.8；提馏段液相 ML=18.0、气相 MV≈32.9 kg/kmol
- **液相平均粘度**：`μL = μA·xF + μB·(1−xF)`（以进料 xF 为基准、全塔平均温度下线性加和，乙醇/水粘度查手册插值），全塔平均 μL≈0.33 mPa·s
- **相对挥发度**：逐板 `αi = yi(1−xi)/[xi(1−yi)]`，几何平均 αm≈1.81
- **总板效率**：`ET = 1.1×0.49(αm·μL)^(−0.245) = 0.61`
- **实际板数**（两段分别向上取整后相加）：精馏段 23/0.61≈37.6→**38 块**、提馏段 3/0.61≈4.9→**5 块**，**总实际板 Ne = 43**（加料板在第 39 块）
- **操作压力**：塔釜表压约 18到20 kPa（不高于 30 kPa）；单板压降以 3.7 验算结果为准

### 3.4 气液相负荷

- 精馏段：`L = RD = 2.55×23.93 = 61.0 kmol/h`；`V = (R+1)D = 84.90 kmol/h`
- 提馏段：`L' = RD + F = 61.0 + 102.80 = 163.8 kmol/h`；`V' = S = 84.90 kmol/h`

> 恒摩尔流下 `L' = W = 163.77 kmol/h`，与上式一致。

### 3.5 工艺尺寸

- 泛点气速 `uF = C·√((ρL−ρG)/ρG)`，C = C20·(σ/20)^0.2（C20 查 Smith 图）
- 空塔气速 `u = 0.8uF`；有效面积 `An = V/u`；总截面积 `A = An/(1−Ad/A)`；`D = √(4A/π)`
- 塔径圆整：≤1000 mm 按 100 mm 递增、>1000 mm 按 200 mm 递增
- 结果：**精馏段 D = 0.90 → 1.0 m**；提馏段 D = 0.72 → 0.8 m（统一用精馏段 1.0 m）
- 塔有效高度：塔板段 `(38−1)×0.35 + (5−1)×0.65 = 15.55 m`，加人孔 8 个×0.6 m = 4.80 m，`HE ≈ 20.35 m`

### 3.6 塔板设计

**3.6.1 溢流装置设计**

- 堰长：`lw = 0.7D = 700 mm`
- 堰上液头：`how = 0.0028Fw(L/lw)^(2/3)`（Fw=1.02）→ **how = 8.1 mm**（要求 >6 mm ✓）
- 板上清液层：`hL = hw + how = 50 mm` → 堰高 **hw = 41.9 mm**
- 降液管（弓形）：宽 **Wd = 143 mm**、面积 **Ad = 0.0689 m²**（Ad/A = 0.0877）、底隙 **hH = 28 mm**

**3.6.2 塔板设计**

- 边缘区 Wc=50 mm、安定区 Ws=60 mm → 鼓泡区 **Aa = 0.4928 m²**
- 筛孔：孔径 d0=5 mm、孔距 t=17 mm（正三角形）、开孔率 `φ = 0.907(d0/t)² = 0.0785`
- 开孔区：`A0 = φ·Aa = 0.0387 m²`；孔数 `n = 1.155·Aa/t² = 1969`
- 孔速：`u0 = V/A0` → 精馏段 **17.59 m/s**、提馏段 **15.15 m/s**；板厚 tp=4 mm

> 孔距取 17 mm（t/d0=3.4）使开孔率降至 7.8%。开孔率过大会使孔速偏低、稳定系数不足（见 3.7）。

### 3.7 流体力学验算（精馏段、提馏段各一套）

**3.7.1 精馏段**

- 单板压降：`ΔHt = h0 + he = 44.95 + 30.00 = 74.95 mm 液柱`
  （`h0 = (1/2g)(u0/C0)²(ρV/ρL)`，C0=0.82；`he = β(hw+how)`，β=0.6）
- 降液管液面：`Hd = hL + hd + ΔHt = 125.30 mm ≤ φ(HT+hw) = 235.11 mm` ✓
  （φ=0.6，降液管阻力 `hd = 0.153[VL/(lw·hH)]²`）
- 停留时间：`τ = Ad·Hd/VL = 9.22 s > 3 s` ✓
- 雾沫夹带（Hunt）：`eV = (0.0057/σ)[u/(HT−2.5hL)]^3.2 = 0.0318 < 0.1` ✓
- 漏液：`h0,min = 0.0056 + 0.13(hw+how) − hσ`、`hσ = 4×10⁻³σ/(ρL·g·d0)`
  → `u0,min = 8.36 m/s`，稳定系数 `K = u0/u0,min = 2.10 > 1.5` ✓

**3.7.2 提馏段**

- 单板压降：`ΔHt = 26.62 + 30.00 = 56.62 mm 液柱`
- 降液管液面：`Hd = 107.24 mm ≤ φ(HT+hw) = 414.10 mm` ✓
- 停留时间：`τ = 5.95 s > 3 s` ✓
- 雾沫夹带：`eV = 0.0011 < 0.1` ✓
- 漏液：`u0,min = 9.28 m/s`，稳定系数 `K = 1.63 > 1.5` ✓

**全塔压降** `= 38×0.0750 + 5×0.0566 m 液柱 = 23.52 kPa ≤ 30 kPa` ✓

**小结**：六项校核（堰上液头、降液管液面、停留时间、雾沫夹带、漏液稳定系数、全塔压降）全部合格。

## 第四章 结果与结论

本设计对日产 24 吨 93.52% 乙醇的乙醇-水筛板精馏塔完成了物料衡算、回流比、理论/实际板数、塔径、塔板结构、流体力学验算、负荷性能图与附属设备选型。

**主要结果**：进料 102.80 kmol/h、塔顶产品 23.93 kmol/h、釜液 163.77 kmol/h、直接蒸汽 84.90 kmol/h；操作回流比 2.55；理论板 25 块（精馏段 23、提馏段 3）、总板效率 0.61、实际板 43 块（精馏段 38、提馏段 5）；塔径 1.0 m；全塔高 23.85 m。

**校核结论**：堰上液头 8.1 mm（>6 mm）、降液管液面精馏段 125.30 mm 与提馏段 107.24 mm（均低于限值）、停留时间 9.22 s 与 5.95 s（>3 s）、液沫夹带 0.0318 与 0.0011（<0.1）、稳定系数 2.10 与 1.63（>1.5）、全塔压降 23.52 kPa（<30 kPa）——**六项流体力学校核全部合格**。负荷性能图操作弹性精馏段 3.01、提馏段 5.78。
